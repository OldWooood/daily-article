# 每日一文 App · 完整方案文档

> 拿着这份文档，在任何地方都可以从零重写出这个 App。
> 环境要求：Android Studio Hedgehog+，JDK 17，Android SDK 34，真机/模拟器需联网。

---

## 1. 产品需求

- 功能：每天一篇文章，读完点底部按钮随机换一篇。
- 界面极简：除底部一个「读完了，随机一篇」按钮外，无任何按钮和设置页。
- 主题跟随系统（深色/浅色，Android 12+ 用动态取色）。
- 文字大小跟随系统（全用 `sp`，不覆盖 `fontScale`）。
- 同一天打开显示同一篇（日期缓存），断网可读旧缓存。
- 数据源挂掉/改版导致解析失败时，自动切换到独立域名的备源，永不白屏。

## 3. 数据源调研（全部实测过）

### 3.1 主源：读书网·每日一读（采用）

- 每日：`https://www.dushu.com/meiwen/`（当天实测标题：蔡澜《人生必到马尔代夫》）
- 随机：`https://www.dushu.com/meiwen/random/`（当天实测：苏童《你丈夫是干什么的》）
- 解析（稳定，无登录无反爬）：
  - 标题：`div.article-detail h1`（兜底 `h1`）
  - 作者：`.article-info`
  - 正文：`div.text`，内含 `h2/h3/p/img`，图片域名 `img.dushu.com`
- 桌面 UA 请求 `www` 站即可（它会把移动端跳到 `m` 站，桌面 UA 留在 `www`）。

### 3.2 备源：ONE·一个 官方 JSON 接口（采用，独立域名）

JSON 比爬 HTML 稳，且 ONE 内容库已冻结归档，接口不会再变。

- 列表（10 条/页，可翻页）：`http://v3.wufazhuce.com:8000/api/channel/reading/more/{游标}`，首屏游标为 `0`，下一页游标取末条的 `id`。
  - 条目字段：`item_id`（文章 id）、`title`、`author.user_name`、`category`。
  - 实测首屏 10 条，翻页正常。
- 详情全文：`http://v3.wufazhuce.com:8000/api/essay/{item_id}`
  - 字段：`data.hp_title`（标题）、`data.hp_author`（作者）、`data.hp_content`（全文 HTML，多为 `<br>` 分隔、无 `<p>` 包裹，实测 15KB/24 段）。
- App 策略：抓 3 页 ≈ 30 篇做候选池；每日取 `dayOfYear % 池大小`（实测当天命中《比海更深｜马航 MH370 消失的三年里》，谢梦遥，24 段）；随机取池内随机下标。

### 3.3 最终保底：一言短句（采用，独立域名）

- `https://v1.hitokoto.cn/?c=d&encode=json`，取 `hitokoto`（句子）、`from`（出处作标题）、`from_who`（作者）。
- 实测返回如：张嘉佳《从你的全世界路过》——“有了艰难的岁月，才可以造就甜美……”。

### 3.4 新增备源（2026-10-01 补充实测）

原方案的 3 个源（读书网 / ONE / 一言）保留，另加 2 个**独立域名**备源，链路由 3 级加深到 5 级：

**备源 A：知乎日报（news-at.zhihu.com，公开 JSON，无需登录）**

- 列表：`https://news-at.zhihu.com/api/4/news/latest` → `stories[]`，字段 `id` / `title` / `hint`（形如 `解磊 · 4 分钟阅读`，取 `·` 前为作者）/ `images[0]`。
- 详情：`https://news-at.zhihu.com/api/4/news/{id}` → `body` 为正文 HTML，实测 4.5KB / 50 个 `<p>` / 2 张图。
- 实测当天：《天生失明的人复明后看到这个世界对精神的冲击会不会很大？》，作者「解磊」。
- 价值：内容质量高（真人故事长文 + 配图），比一言有阅读价值得多。

**备源 B：每日 60 秒读懂世界（60s.viki.moe，开源 JSON）**

- 当天：`https://60s.viki.moe/v2/60s`；**支持 `?date=YYYY-MM-DD` 查历史任意一天**（实测 `?date=2026-09-15` 正常返回），可做按日期取。
- 字段：`data.date` / `data.news[]`（15 条每日新闻）/ `data.tip`（微语）/ `data.link`。
- 镜像域名 `60s-api.viki.moe/v2/60s` 同样可用，`60s.b23.run` 需带 `/v2` 前缀。
- 价值：结构固定、从不解析失败，适合做「绝不会失败」的那一层。

### 3.5 高质量文学源（2026-10-01 新增，均已实测）

技术类源（少数派/爱范儿/阮一峰）已下掉（与文学定位不符），散文类老站多已死亡
（sanwen.net 证书过期、meiwen/duwenzhang 主站 https 失败、sanwen8.cn/shiguwen 失联），
实测可用 3 个独立域名文学源，全部免登录，排在 60 秒简报之前：

**备源 C：散文网（sanwenwang.com，原 sanwen.net）**——与主源同定位

- 列表：`/sanwen/` `/suibi/` `/zawen/`（散文/随笔/杂文，诗歌太短不收），
  每页约 26 篇文章链接（`/sanwen/xxx.html`），3 分类共 70+ 篇做池。
  **必须桌面 UA**：移动 UA 会被 302 到 `m.sanwen.net`（另一套移动站，真机实测）。
- 详情：标题 `div.title h1`，作者 `div.info a`，正文 `div.content p`；
  需去掉 `.adcontent` 广告与 `style*=-100000` 隐藏 SEO 灌水。
- 每日取 `dayOfYear % 池大小`，随机取池内随机下标，详情失败顺着池子往下试。

**备源 D：短文学/文章阅读网（duwenzhang.com，GB2312）**

- 列表：`meiwen.html` + `sanwen.html` 的 `/wenzhang/…/*.html` 链接去重成池。
- 详情：标题 `h1`，作者 `td.author a`（老文章该链接为空，退到 `作者：(\S+)` 纯文本正则，
  并过滤掉误抓的 `来源：/时间：`），正文 `div#wenzhangziti p`（站内大写 `<P>`，Jsoup 自动归一）。
- 全站 GBK 编码，靠 `Http` 的「响应头 charset → meta charset → UTF-8」自适应解码。

**备源 E：古文岛/原古诗文网（gushiwen.cn）**——古典文学，0.25 秒极快

- 列表：`/shiwens/` 的 `/shiwenv_xxx.aspx` 链接（约 10 首，少但稳定），
  且带 `Cache-Control: public, max-age=7200`，命中内存/HTTP 缓存。
  **必须桌面 UA**：移动 UA 只返回 158 字节占位页（真机实测）；单点请求失败重试 3 次。
- 详情：标题 `h1`，作者 `p.source` 的两个链接（人名 + 朝代），
  原诗 `div.contson` 以 `<br>` 分行，按行成段（译文/赏析走 JS 异步接口，静态抓不到，只取原诗）。

### 3.6 淘汰的源（及原因，含 2026-10-01 新增排查）

- `meiriyiwen.com` 官网及 `interface.meiriyiwen.com/article/today?dev=1` / `random?dev=1`：多次实测超时，不可靠。
- `m.dushu.com`：与主源同域名，一起挂，不算备份。
- `duwenzhang.com/meiwen.html`：GBK 编码、广告多、无官方随机页，被否决。
- `chengww5217/one_article` 引用的 `jokermonn/-Api` 文档页：404，已失效。

## 4. 架构设计

- 单 `Activity` + Compose Material3 + `AndroidViewModel`。
- 数据模型：`Article(title, author, blocks, source)`，`Block` 分 `Para`（段落）/`Subhead`（小标题）/`Image`（图片）。
- 状态：`Loading / Done(article, isRandom) / Error(msg, isRandom)`。
- **抽象出 `ArticleSource` 接口**（`name` / `fetchDaily()` / `fetchRandom()`），每个源一个类；`SourceChain` 负责按序 `runCatching`，首个成功者胜出。加新源 = 加一个类，不改 ViewModel。
- 故障转移链（均为独立域名，文学优先）：
  - 每日：磁盘当天缓存 → **读书网 → 散文网 → 短文学 → ONE·一个 → 知乎日报 → 古诗文 → 60秒简报 → 一言** → 旧缓存 → 报错。
  - 随机：同上顺序 → 报错（随机不写缓存）。
- 日期缓存：`SharedPreferences("daily_cache")` 存 `date + title + author + source + blocks(JSON)`，零新依赖。当天命中直接显示；每日抓取失败用旧缓存兜底。
- 换随机体验：已有文章在读时不闪整屏菊花，老文章保留可读，顶部只露一条细进度条，按钮禁用防连点。
- 移动 UA 坑（真机实测）：散文网移动 UA 会被 302 到 `m.sanwen.net`、古诗文移动 UA 只回 158 字节占位页，两者详情与列表一律用桌面 UA。
- 关键细节：源抓到页面但正文为空也算解析失败，**必须抛异常**才能进下一个源。
- 图片：Coil；网络：`HttpURLConnection` + `org.json`（系统自带，含 gzip 解压）；HTML：Jsoup。
- 依赖：`compose-bom 2024.09.00`、material3、activity-compose、lifecycle-viewmodel-compose、jsoup 1.17.2、coil-compose 2.6.0。`minSdk 26`（`java.time.LocalDate` 需要）。

### 4.1 原方案的两处 bug（已修）

1. **Manifest 缺 `usesCleartextTraffic`**：ONE 接口是 `http://v3.wufazhuce.com:8000` 明文，targetSdk 28+ 默认禁止明文流量，不加这个属性 ONE 会被系统直接拦掉（表现为连接失败而非解析失败，很难排查）。
2. **`jsoupGet` 与 `httpGet` 混用会重复请求**：主源应「一次请求 → 同一份 html → 解析」，不要在解析函数里再发一次请求。

/** 当天缓存：同一天打开显示同一篇，存在 SharedPreferences，无需新依赖。 */

        val arr = JSONArray()
        for (b in a.blocks) when (b) {
            is Block.Para -> arr.put(JSONObject().put("t", "p").put("c", b.text))
            is Block.Subhead -> arr.put(JSONObject().put("t", "s").put("c", b.text))
            is Block.Image -> arr.put(JSONObject().put("t", "i").put("c", b.url))
        }
        ctx.getSharedPreferences(NAME, Context.MODE_PRIVATE).edit()
            .putString(K_DATE, today())
            .putString(K_TITLE, a.title)
            .putString(K_AUTHOR, a.author)
            .putString(K_BLOCKS, arr.toString())
            .apply()
    }

    private fun read(sp: android.content.SharedPreferences): Article? {
        val title = sp.getString(K_TITLE, null) ?: return null
        val blocks = mutableListOf<Block>()
        val arr = JSONArray(sp.getString(K_BLOCKS, "[]"))
        for (i in 0 until arr.length()) {
            val o = arr.optJSONObject(i) ?: continue
            when (o.optString("t")) {
                "p" -> blocks.add(Block.Para(o.optString("c")))
                "s" -> blocks.add(Block.Subhead(o.optString("c")))
                "i" -> blocks.add(Block.Image(o.optString("c")))
            }
        }
        if (blocks.isEmpty()) return null
        return Article(title, sp.getString(K_AUTHOR, null).orEmpty(), blocks)
    }
}

class ArticleViewModel(app: Application) : AndroidViewModel(app) {
    private val _state = MutableStateFlow<UiState>(UiState.Loading)
    val state: StateFlow<UiState> = _state

    init { load(daily = true) }

    fun loadDaily() = load(daily = true)
    fun loadRandom() = load(daily = false)

    private fun load(daily: Boolean) {
        viewModelScope.launch {
            if (daily) {
                // 1. 当天缓存命中则直接用，不请求网络
                val cached = withContext(Dispatchers.IO) { DailyCache.loadToday(getApplication()) }
                if (cached != null) {
                    _state.value = UiState.Done(cached, isRandom = false)
                    return@launch
                }
            }
            _state.value = UiState.Loading
            try {
                val a = withContext(Dispatchers.IO) {
                    if (daily) fetchDaily() else fetchRandom()
                }
                if (daily) withContext(Dispatchers.IO) { DailyCache.saveToday(getApplication(), a) }
                _state.value = UiState.Done(a, isRandom = !daily)
            } catch (e: Exception) {
                // 2. 每日失败时兜底：有旧缓存就显示旧的，保证断网可读
                val fallback = if (daily) withContext(Dispatchers.IO) {
                    DailyCache.loadAny(getApplication())
                } else null
                _state.value = if (fallback != null) UiState.Done(fallback, isRandom = false)
                else UiState.Error("加载失败：${e.message ?: "网络错误"}", isRandom = !daily)
            }
        }
    }

    // 故障转移链（均为独立域名）：读书网 -> ONE·一个 -> 一言短句保底
    private fun fetchDaily(): Article {
        runCatching { return fetchDushu(URL_DAILY) }
        runCatching { return fetchOneDaily() }
        return fetchHitokoto()
    }

    private fun fetchRandom(): Article {
        runCatching { return fetchDushu(URL_RANDOM) }
        runCatching { return fetchOneRandom() }
        return fetchHitokoto()
    }

    // 主源：读书网，已用 Python 验证 h1=标题，.article-info=作者，div.text=正文
    private fun fetchDushu(url: String): Article {
        val doc = Jsoup.connect(url).userAgent(UA).timeout(15_000).get()
        val title = doc.selectFirst("div.article-detail h1")?.text()?.trim()
            ?: doc.selectFirst("h1")?.text()?.trim().orEmpty()
        val author = doc.selectFirst(".article-info")?.text()?.trim().orEmpty()
        val body = doc.selectFirst("div.text") ?: throw IllegalStateException("正文解析失败")
        val blocks = mutableListOf<Block>()
        for (el in body.select("h2, h3, p, img")) {
            when (el.tagName()) {
                "img" -> {
                    val src = el.attr("abs:src").ifEmpty { el.attr("src") }
                    if (src.isNotBlank()) blocks.add(Block.Image(src))
                }
                "h2", "h3" -> el.text().trim().takeIf { it.isNotEmpty() }?.let {
                    blocks.add(Block.Subhead(it))
                }
                else -> el.text().trim().takeIf { it.isNotEmpty() }?.let {
                    blocks.add(Block.Para(it))
                }
            }
        }
        // 兜底：img 可能包在 div 里
        if (blocks.none { it is Block.Image }) {
            body.select("img").forEach {
                val src = it.attr("abs:src").ifEmpty { it.attr("src") }
                if (src.isNotBlank()) blocks.add(Block.Image(src))
            }
        }
        // 正文为空视为解析失败，触发故障转移到备源
        if (blocks.isEmpty()) throw IllegalStateException("正文为空")
        return Article(title.ifEmpty { "每日一读" }, author, blocks)
    }

    // 备源：ONE·一个(wufazhuce.com，独立域名，JSON接口，已验证)
    // 阅读频道列表 10条/页可翻页，详情 hp_content 为全文
    private fun fetchOneDaily(): Article {
        val pool = fetchOnePool()
        val idx = (LocalDate.now().dayOfYear % pool.size + pool.size) % pool.size
        return fetchEssay(pool[idx])
    }

    private fun fetchOneRandom(): Article {
        val pool = fetchOnePool()
        return fetchEssay(pool[kotlin.random.Random.nextInt(pool.size)])
    }

    private data class OneItem(val essayId: String, val title: String, val author: String)

    // 抓3页≈30篇做候选池；单页失败不影响已有成果
    private fun fetchOnePool(): List<OneItem> {
        val out = mutableListOf<OneItem>()
        var cursor = "0"
        repeat(3) {
            val arr = JSONObject(httpGet(URL_ONE_MORE + cursor)).getJSONArray("data")
            if (arr.length() == 0) return out.ifEmpty { throw IllegalStateException("ONE列表为空") }
            for (i in 0 until arr.length()) {
                val o = arr.getJSONObject(i)
                val eid = o.optString("item_id")
                if (eid.isNotBlank()) out.add(
                    OneItem(eid, o.optString("title"), o.optJSONObject("author")?.optString("user_name").orEmpty())
                )
            }
            cursor = arr.getJSONObject(arr.length() - 1).optString("id", cursor)
        }
        return out.ifEmpty { throw IllegalStateException("ONE列表为空") }
    }

    private fun fetchEssay(it: OneItem): Article {
        val d = JSONObject(httpGet(URL_ONE_ESSAY + it.essayId)).getJSONObject("data")
        val title = d.optString("hp_title").ifBlank { it.title }.ifBlank { "ONE·一个" }
        val author = d.optString("hp_author").ifBlank { it.author }
        val paras = Jsoup.parseBodyFragment(d.optString("hp_content"))
            .select("p").map { it.text().trim() }.filter { s -> s.isNotEmpty() }.toMutableList()
        if (paras.isEmpty()) {
            // hp_content多为<br>分隔、无<p>包裹，按<br>切分
            val html = d.optString("hp_content").replace(Regex("<br\\s*/?>", RegexOption.IGNORE_CASE), "\n")
            paras += Jsoup.parseBodyFragment(html).body().text()
                .split("\n").map { s -> s.trim() }.filter { s -> s.isNotEmpty() }
        }
        if (paras.isEmpty()) throw IllegalStateException("ONE正文为空")
        return Article(title, author, paras.map { s -> Block.Para(s) })
    }

    private fun httpGet(url: String): String {
        val c = (java.net.URL(url).openConnection() as java.net.HttpURLConnection).apply {
            setRequestProperty("User-Agent", UA)
            connectTimeout = 15_000
            readTimeout = 15_000
        }
        try {
            if (c.responseCode !in 200..299) throw IllegalStateException("HTTP ${c.responseCode}")
            return c.inputStream.bufferedReader().readText()
        } finally {
            c.disconnect()
        }
    }

    // 最终保底：一言短句，保证永不白屏
    private fun fetchHitokoto(): Article {
        val o = JSONObject(httpGet(URL_HITOKOTO))
        val s = o.optString("hitokoto")
        if (s.isBlank()) throw IllegalStateException("一言为空")
        return Article(o.optString("from").ifBlank { "一言" }, o.optString("from_who"), listOf(Block.Para(s)))
    }
}

@Composable
fun DailyApp(vm: ArticleViewModel = viewModel()) {
    // 主题跟随系统：Android 12+ 用动态取色，否则跟随深浅
    val ctx = LocalContext.current
    val dark = isSystemInDarkTheme()
    val scheme = when {
        Build.VERSION.SDK_INT >= Build.VERSION_CODES.S ->
            if (dark) dynamicDarkColorScheme(ctx) else dynamicLightColorScheme(ctx)
        dark -> darkColorScheme()
        else -> lightColorScheme()
    }
    // 注意：全程用 MaterialTheme.typography（单位 sp），不覆盖 fontScale，
    // 文字大小自动跟随系统设置。
    MaterialTheme(colorScheme = scheme) {
        val state by vm.state.collectAsState()
        Scaffold(
            bottomBar = {
                // 唯一的操作按钮，满足“读完了随机一篇”
                Button(
                    onClick = { vm.loadRandom() },
                    enabled = state !is UiState.Loading,
                    modifier = Modifier
                        .fillMaxWidth()
                        .padding(16.dp)
                ) { Text("读完了，随机一篇") }
            }
        ) { pad ->
            Box(Modifier.fillMaxSize().padding(pad)) {
                when (val s = state) {
                    is UiState.Loading -> CircularProgressIndicator(Modifier.align(Alignment.Center))
                    is UiState.Error -> Column(
                        Modifier.fillMaxSize().padding(24.dp),
                        horizontalAlignment = Alignment.CenterHorizontally,
                        verticalArrangement = Arrangement.Center
                    ) {
                        Text(s.msg, textAlign = TextAlign.Center)
                        Spacer(Modifier.height(12.dp))
                        Button(onClick = { if (s.isRandom) vm.loadRandom() else vm.loadDaily() }) {
                            Text("重试")
                        }
                    }
                    is UiState.Done -> ArticleBody(s.article)
                }
            }
        }
    }
}

@Composable
fun ArticleBody(a: Article) {
    LazyColumn(
        Modifier.fillMaxSize().padding(horizontal = 20.dp),
        contentPadding = androidx.compose.foundation.layout.PaddingValues(vertical = 16.dp)
    ) {
        item {
            Text(
                a.title,
                style = MaterialTheme.typography.headlineSmall,
                textAlign = TextAlign.Center,
                modifier = Modifier.fillMaxWidth()
            )
            if (a.author.isNotBlank()) {
                Spacer(Modifier.height(8.dp))
                Text(
                    a.author,
                    style = MaterialTheme.typography.bodyMedium,
                    color = MaterialTheme.colorScheme.onSurfaceVariant,
                    textAlign = TextAlign.Center,
                    modifier = Modifier.fillMaxWidth()
                )
            }
            Spacer(Modifier.height(12.dp))
            HorizontalDivider()
            Spacer(Modifier.height(12.dp))
        }
        items(a.blocks) { b ->
            when (b) {
                is Block.Subhead -> {
                    Spacer(Modifier.height(8.dp))
                    Text(b.text, style = MaterialTheme.typography.titleMedium)
                    Spacer(Modifier.height(4.dp))
                }
                is Block.Para -> {
                    Text(
                        "　　" + b.text,
                        style = MaterialTheme.typography.bodyLarge,
                        lineHeight = MaterialTheme.typography.bodyLarge.lineHeight * 1.6
                    )
                    Spacer(Modifier.height(8.dp))
                }
                is Block.Image -> {
                    AsyncImage(
                        model = b.url,
                        contentDescription = null,
                        modifier = Modifier.fillMaxWidth().padding(vertical = 8.dp)
                    )
                }
            }
        }
        item { Spacer(Modifier.height(32.dp)) } // 给底部按钮留白
    }
}
